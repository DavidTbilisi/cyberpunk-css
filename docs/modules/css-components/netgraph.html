NetGraph (CSS)

JavaScript adds the .cp-netgraph root and child classes (.cp-netgraph__canvas, .cp-netgraph__edge, .cp-netgraph__arrow-head, etc.). Style them in scss/_netgraph.scss or override in your app.

Layout size

The plot area (.cp-netgraph__canvas) uses a responsive height (clamp and min(…vh)) so the graph reads larger on wide screens. The SVG stretches to fill the canvas; internal layout defaults to 1200×560 viewBox units unless you pass width / height to renderNetGraph.

Usage

<div id="net" style="width:100%;max-width:1100px"></div>
<script type="module">
  import { renderNetGraph } from '../../../scripts/netgraph.js';
  renderNetGraph('#net', { nodes: [...], edges: [...] }, { title: 'LAN' });
</script>

Directed edges and flow behaviour are documented in netgraph module.
